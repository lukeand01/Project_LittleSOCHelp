API quickstart

GET or POST

Query parameter for GET, JSON with an indicator field for POST.

GET /api/lookup?indicator=1.2.3.4
POST /api/lookup · {"indicator":"example.com"}

Normalized verdict

Returns malicious, clean, or unknown with provider evidence and consensus.

AbuseIPDB · IP reputationURLhaus · URLs / domainsOTX · all indicator types

Server configuration

Add credentials in Render service Environment settings → Environment Variables. Keys are used only by the server function.

ABUSEIPDB_API_KEYURLHAUS_AUTH_KEYOTX_API_KEY

Missing keys leave that source unavailable. Partial verdicts still return.

Community threat data is a signal, not a guarantee of safety. “Clean” means no configured source flagged the indicator.
